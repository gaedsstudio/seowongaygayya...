# 아트와 UI 디자인 가이드

이 게임의 화면을 **누가 작업하든(사람이든 AI든) 같은 게임처럼 보이게** 하기 위한 규칙입니다.
여기서 벗어나야 하면, 먼저 이 문서를 고치는 PR을 올리고 합의하세요.

---

## 1. 비주얼 콘셉트

- **"어둠 속에서 늘어나는 보라색 군단"**: 차갑고 어두운 던전 바닥 위에서 아군은 **보라색**, 적(용사)은 **원래의 밝은 색**으로 보인다. 게임이 진행될수록 화면에 보라색이 많아져야 한다.
- 레퍼런스 무드: 화면 가득한 적 무리, 겹쳐 떠오르는 붉은 데미지 숫자, 빛나는 경험치 보석, 넓게 깔리는 장판 이펙트. 탑다운 서바이벌 장르 특유의 정보 과잉에서 오는 쾌감.
- 키워드: `16비트 픽셀` · `던전` · `보라와 금` · `영혼의 청색` · `혼돈스럽지만 읽히는 화면`

## 2. 픽셀아트 규칙

| 항목 | 규칙 |
|---|---|
| 기본 그리드 | **16×16 px**. 캐릭터는 16×16, 16×23, 16×28. 큰 몬스터는 32×36 |
| 원근 | 탑다운에서 살짝 비스듬히 본 시점 (0x72 DungeonTileset II 기준) |
| 앵커 | 모든 캐릭터는 **발밑 가운데**가 좌표 (x, y)다. `drawFrame` 기본값이 `anchorX 0.5, anchorY 1` |
| 바라보는 방향 | 원본 스프라이트는 **오른쪽**을 본다. 왼쪽은 `flip`으로 처리한다 |
| 무기/발사체 | 원본은 **위쪽**을 향한다. 회전은 `atan2(vy, vx) + π/2` |
| 애니메이션 | 4프레임. 이동 10fps, 대기 6fps. 이름 규칙은 `<base>_run_anim_f0..3` / `<base>_idle_anim_f0..3` / `<base>_anim_f0..3` |
| 스케일 | 정수 줌만 쓴다 (`CONFIG.VIEW_H` 기준, 최소 2배). 보스만 `scale` 2~2.8배를 허용한다 |
| 보간 | `imageSmoothingEnabled = false`, CSS `image-rendering: pixelated` |
| 외곽선 | 원본 에셋 스타일을 따른다(어두운 외곽선). 새로 그리는 스프라이트도 1px 어두운 외곽선을 넣는다 |

### 3.1 아군과 적 구분 (가장 중요)
| 대상 | 표현 |
|---|---|
| 용사(적) | 원본 색 그대로 |
| 마물(아군) | 원본 색 + 발밑에 **보라색 타원 발광** |
| 빙의 용사 | 스프라이트 전체에 보라 틴트 `#a64dff` 45% + 발광 |
| 타락한 보스 | 짙은 보라 틴트 `#6a1fb8` 45% + 발광 |
| 시체 | 90도로 눕히고 어두운 틴트 `#2b2233` 55%, 수명이 끝나면 페이드 |
| 피격 | 0.08초 동안 흰색 틴트 |

## 4. 타이포그래피

- 폰트: **Galmuri11** (보통, 굵게). 한글을 지원하는 픽셀 폰트다. 다른 폰트는 쓰지 않는다.
- 캔버스 HUD는 `s = round(화면높이 / 360)`을 UI 픽셀 단위로 삼고, 글자 크기는 `7s`(보조), `8~9s`(본문), `14~16s`(타이머, 배너)
- 캔버스 텍스트에는 항상 `#0a0410` 외곽선(strokeText)을 넣어 혼잡한 배경 위에서도 읽히게 한다.
- 한국어 줄바꿈: DOM에서는 `word-break: keep-all`

## 5. UI 레이아웃 (HUD)

```
┌──────────────────────── XP 바 (화면 전체 폭) ─────────────── LV n ┐
│ [주문 아이콘 ×6]             10:00              처치 1234        │
│ [유물 아이콘 ×6]        보스 접근 30초       군단 12/18 · 전체 40 │
│ 사령 제단 ████████                                               │
│                                                                  │
│                         (네크로맨서)                              │
│                          ▀▀▀▀ HP                                 │
│                                                                  │
│ 대빙의 게이지                [보스 이름]                          │
│ ██████                     ███████████████                       │
└──────────────────────────────────────────────────────────────────┘
```

- 위쪽 가장자리: 진행 정보 (경험치, 시간, 처치 수)
- 왼쪽 위: 내 빌드 (아이콘 오른쪽 아래에 레벨 숫자. 최대 레벨은 금색 `M`)
- 아래쪽 가장자리: 위협 (보스 체력) + 내 필살기 (대빙의)
- 가운데 배너: 이벤트 알림 (3.2초)
- 패널(DOM)은 금테 2px + 검정 1px + 짙은 금 1px의 **3중 테두리**를 쓴다.
- 레벨업 카드: 아이콘 64px, 태그(새 주문/주문 Lv/새 유물), 이름(금색), 변화 수치("피해 10 → 13")
- 모바일(터치)에서는 화면 어디든 드래그하면 가상 조이스틱이 생기고, 우하단에 원형 대빙의 버튼이 나온다.

## 6. 이펙트 (VFX)

| 이펙트 | 표현 | 색 |
|---|---|---|
| 영혼 화살 | 3px 코어 + 6px 글로우 + 잔상 파티클 | `#b8f6ff` / 청색 |
| 성광구 (적) | 같은 구조 | `#fff3c4` / 금빛 |
| 지옥불 (아군 원거리) | 같은 구조 | 연두 |
| 죽음의 장막 | 반투명 보라 원 + 회전하는 점선 테두리 | `#4a1a7a`, `#9b5cff` |
| 역병 웅덩이 | 두 겹 타원 (바깥 짙은 녹색, 안 형광 녹색) + 올라가는 기포 | 녹색 |
| 시체 폭발 | 주황 링 + 불꽃 파티클 + 붉은 살점 + 약한 화면 흔들림 | `#ff9a3c` |
| 소환 | 보라 파티클이 떠오르고 땅에서 솟아나는 연출(0.6초) | `--evil` |
| 대빙의 | 큰 보라 링 + 흰 링 + 보라 화면 플래시 + 흔들림 | `#c27bff` |
| 보스 처치 | 금색 링 + 강한 흔들림 → 1.6초 뒤 보라 기둥과 함께 타락 부활 | 금색, 보라 |

- 파티클은 **사각형 1~2px**만 쓴다 (원형 파티클 금지. 픽셀 스타일 유지)
- 성능 상한: 파티클 900, 데미지 숫자 160, 발사체 600 (`src/config.js`)

## 7. 에셋 반입 규칙

1. **라이선스 확인 필수**: CC0, CC-BY, 또는 "상업적 이용 가능하고 재배포 가능"이 명시된 에셋만 쓴다. itch.io 에셋은 페이지의 *More information → License* 를 확인한다. **재배포가 금지된 에셋(대부분의 유료 팩)은 저장소에 커밋하지 않는다.**
2. **스타일 일치**: 16×16 그리드, 어두운 외곽선, 채도가 비슷한 에셋만 쓴다. 0x72 DungeonTileset II와 섞어 놓고 어색하면 쓰지 않는다.
3. **기록**: [CREDITS.md](../CREDITS.md)에 이름, 파일, 제작자, URL, 라이선스를 적는다.
4. **아틀라스 등록**: 스프라이트시트를 `assets/sprites/`에 넣고 `이름 x y w h` 형식의 목록 파일을 만든 뒤, `tools/build_atlas.py`의 `SOURCES`에 추가하고 `python3 tools/build_atlas.py`를 실행한다. 새 이미지 키는 `src/core/assets.js`의 `IMAGES`에도 추가한다.
5. **이름 규칙**: 프레임 이름은 `snake_case`, 애니메이션은 `_anim_f0`부터 시작한다.

## 8. 하지 말 것

- 실존 게임의 캐릭터, 로고, UI를 그대로 베끼기
- 정수가 아닌 배율로 픽셀아트를 그리기 (보스 `scale`은 예외)
- 원형 그라디언트로 된 부드러운 파티클 (비네트, 글로우 원은 예외)
- 아군을 적과 같은 색으로 두기 (아군에는 반드시 보라 신호가 있어야 함)
- UI 텍스트에 외곽선 없이 밝은 색만 쓰기
