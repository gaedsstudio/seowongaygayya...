## 1. 개요

| 항목 | 내용 |
|---|---|
| 제목 | 포제션 디펜스 (Possession Defense) |
| 한 줄 소개 | 용사 파티를 상대하는 네크로맨서가 되어 몬스터 군단을 만들고 용사 파티를 무찌른다 |
| 장르 | 탑다운 서바이벌 액션(자동 공격, 레벨업 선택지) + 거점 방어 |
| 플레이 시간 | 한 판 약 10분. 10:00에 최종 보스 등장 |
| 플랫폼 | 웹 브라우저 (PC, 모바일) |
| 시점/그래픽 | 탑다운 16×16 픽셀아트, 어두운 던전 |

### 1.1 기획 의도

> 용사가 주인공이 되는 게임이 많아서, 역발상으로 **나쁜 역할의 주인공**이 되어 용사파티를 토벌하는 내용을 담고 싶었다.

이 의도에서 나온 디자인 원칙은 세 가지입니다.

1. **악역의 쾌감**: 용사들이 몰려오지만 결국 플레이어의 군단에 삼켜진다. 화면이 "내 편"으로 뒤덮이는 순간이 핵심 보상이다.
2. **적이 곧 자원**: 쓰러진 용사의 시체는 내 마물이 되고, 살아있는 용사는 빙의해 내 편이 되고, 보스는 쓰러지면 **타락해서 내 동료**가 된다. 적을 죽이는 일이 군단을 키우는 일과 같다.
3. **지켜야 할 곳이 있다**: 일반 서바이벌 게임과 다르게, 던전 중앙의 **사령 제단**을 지켜야 한다. 그래서 "앞으로 나가 사냥하기"와 "돌아와서 지키기" 사이에서 긴장이 생긴다.

### 1.2 레퍼런스

- 장르 문법: 자동 공격, 몰려오는 적 무리, 경험치 보석, 레벨업 3지선다 같은 탑다운 서바이벌 장르의 공통 규칙을 따른다.
- 차별점: **소환과 빙의로 군단을 키우는 것**과 **거점 방어**. 특정 게임을 그대로 따라 만들지 않는다.

## 2. 세계관과 등장인물

- **배경**: 마왕이 쓰러진 뒤, 왕국은 남은 마왕군을 없애려고 용사 파티를 보낸다. 마지막 남은 마왕군 간부인 **네크로맨서(플레이어)** 는 지하 던전의 **사령 제단**을 지키며 반격을 준비한다.
- **플레이어: 이름 없는 네크로맨서**. 말이 없다. 행동으로 말한다.
- **용사 파티 (보스)**

| 보스 | 역할 | 등장 | 특징 |
|---|---|---|---|
| 엘프 레인저 **실바** | 궁수 | 2:30 | 부채꼴 화살 |
| 드워프 장군 **브론** | 방패 | 5:00 | 돌진 |
| 대마법사 **세레나** | 마법사 | 7:30 | 원형 탄막, 견습 마법사 소환 |
| 성녀 **엘리아** | 성녀 | 10:00 | 회복 파동, 사제 소환, 탄막 |
| 용사 **레온** | 최종 보스 | 10:00 | 돌진, 광역 베기, 기사 소환. **처치하면 승리** |

- **톤**: 어둡지만 무겁지 않다. 보스 대사는 짧고 진지하며, 타락한 뒤의 대사로 반전을 준다.
  - 예: 실바 "어둠의 술사여, 숲의 이름으로 너를 쏘아 맞히겠다!" → 타락 후 "...화살은 이제 주인님을 위해."

## 3. 핵심 루프

```
 이동하며 생존 ─▶ 자동 주문이 용사를 처치 ─▶ 영혼 보석(경험치) + 시체
      ▲                                         │
      │                                         ▼
 레벨업: 주문/유물 1개 선택 ◀── 보석 수집      사령 소생: 시체 → 마물
      │                                         │
      └──── 더 강한 군단으로 더 많은 용사를 처치 ◀┘
                 (가끔 제단으로 돌아가 방어)
```

- **30초 루프**: 보석 줍기, 레벨업 선택, 제단 확인
- **2~3분 루프**: 이벤트(포위, 제단 습격), 보스 등장, 보스가 타락해서 아군이 됨
- **10분 루프**: 최종 결전. 레온을 처치하면 승리

## 4. 시스템

### 4.1 플레이어 (네크로맨서)
- 이동만 직접 조작한다. 공격은 모두 **자동 시전**이다.
- 기본값: 체력 120, 이동속도 62 px/s (`src/config.js` → `PLAYER`)
- 체력이 0이 되면 패배한다.
- 제단 근처(반경 56)에 있으면 초당 4씩 체력을 회복한다.

### 4.2 사령 제단 (방어 거점)
- 아레나(2400×2400) 중앙에 있다. 체력 1000이고 초당 2씩 재생한다.
- 반경 120 안의 용사에게 **자동으로 영혼 화살**을 쏜다. 피해는 플레이어 레벨에 비례해 커진다.
- 용사의 일부(`altarBias`)와 **제단 습격 이벤트**가 제단을 노린다.
- 용사가 제단에 주는 피해는 50%로 줄어든다. 빗나간 화살은 제단에 맞지 않고, 제단을 직접 조준한 공격만 맞는다.
- **체력이 0이 되면 패배**한다. 제단이 화면 밖에서 공격받으면 HUD 화살표가 빨갛게 깜빡인다.

### 4.3 군단 (아군)
| 종류 | 얻는 방법 | 수명 | 상한 |
|---|---|---|---|
| **마물** (minion) | `사령 소생`이 시체를 되살림 | 죽을 때까지 | 사령 소생 레벨의 cap + `군단장의 깃발` |
| **빙의 용사** (possessed) | `빙의` 주문 | 죽을 때까지 | 빙의 레벨의 cap |
| **대빙의 용사** | SPACE (게이지 100%) | 15초 | 한 번에 최대 40명 |
| **타락한 영웅** (fallen) | 보스를 처치하면 1.6초 뒤 자동으로 부활 | 죽을 때까지 | 상한 없음 |

- 마물 티어: 1티어(해골, 꼬마 좀비, 고블린, 임프) / 2티어(구울, 오크 전사, 가면 오크, 초르트, 오크 주술사) / 3티어(거대 구울, 오우거, 대악마)
- 군단은 평소 플레이어 주위를 호위하고, 반경 115 안에 용사가 있으면 공격한다. 플레이어와 210 넘게 떨어지면 돌아온다.
- 군단의 체력과 공격력은 플레이어 레벨마다 6%씩 오른다.

### 4.4 주문 (자동 시전, 최대 6개, 각 6레벨)
| 주문 | 역할 | 비고 |
|---|---|---|
| 영혼 화살 | 기본 단일 유도 | 시작 주문 |
| 사령 소생 | **군단 생성** | 시작 주문. 레벨 3에서 2티어, 레벨 5에서 3티어 해금 |
| 죽음의 장막 | 근접 지속 광역 | 주변을 계속 썩게 함 |
| 역병 웅덩이 | 무리 지역 피해 | 적이 몰린 곳에 장판 |
| 뼈창 | 관통 직선 | 넉백이 강함 |
| 시체 폭발 | 시체를 소모하는 광역 폭발 | **사령 소생과 시체를 두고 경쟁**하는 선택 |
| 빙의 | 강한 용사를 영구히 아군으로 | 보스는 제외 |

### 4.5 유물 (패시브, 최대 6개, 각 5레벨)
망자의 육신(체력) · 그림자 걸음(이속) · 심연 확장(범위) · 시간 왜곡(쿨다운) · 금단의 지식(주문 피해) ·
어둠의 계약(군단 공/체) · 군단장의 깃발(군단 상한) · 영혼 흡인(획득 범위) · 제단의 가호(제단 강화)

### 4.6 성장
- 레벨 n에서 다음 레벨까지 필요한 경험치: `6 + 4n + 0.8·n^1.5` (`src/game.js` → `xpForLevel`)
- 레벨업할 때마다 3개 중 1개를 고른다. 가중치는 보유 주문 강화 3, 새 주문 2, 보유 유물 2, 새 유물 1.5
- 모든 슬롯이 꽉 차고 모두 최대 레벨이면 대체 보상(체력 회복, 대빙의 게이지)이 나온다.
- 대빙의 게이지: 일반 처치마다 0.8%, 보스 처치에 30%

### 4.7 적 (용사 측)
| 용사 | AI | 특징 |
|---|---|---|
| 견습 기사 | 근접 | 기본 병력 |
| 왕국 여기사 | 근접 | 중급 |
| 리자드 척후병 | 근접 | 빠름. 제단을 자주 노림 |
| 엘프 궁수 | 원거리 | 화살 |
| 견습 마법사 | 원거리 | 느린 성광구 |
| 드워프 방패병 | 근접 | 탱커. 넉백 저항 |
| 드워프 광전사 | 근접 | 빠르고 아픔 |
| 수련 사제 | 힐러 | 다친 용사를 회복 |
| 성기사 | 근접 | 3:00부터 등장. 5초마다 방패 오라: 반경 48 안의 용사가 3초 동안 받는 피해 -40%. 넉백 저항 |

- 빙의된 성기사의 방패 오라는 같은 편인 군단뿐 아니라 **플레이어와 사령 제단**에도 걸린다 (제단은 원래 피해 감소 50%에 곱해짐).
- 일반 용사의 체력은 시간에 따라 `1 + 경과초/200` 배로 오른다.
- 용사는 근처에 있는 마물이나 플레이어를 먼저 공격하고, 없으면 자기 목표(플레이어 또는 제단)로 진군한다.

### 4.8 웨이브 (`src/data/waves.js`)
- 상시 스폰: 시간대별로 간격, 묶음 수, 필드 최대 수, 병종 비율을 정한다.
- 이벤트: 1:00 포위 → 1:40 제단 습격 → **2:30 실바** → 3:30 궁수 포위 → 4:20 습격 → **5:00 브론** → 6:00 기사단 포위 → 7:00 습격 → **7:30 세레나** → 8:30 마법사 포위 → 9:20 습격 → **10:00 레온 + 엘리아**

### 4.8.1 유적 (맵 오브젝트, `src/data/sites.js`)
아레나 곳곳에 처음부터 놓여 있는 오브젝트. 제단에서 멀리 나가게 만드는 **위험과 보상**이 목적이다. 화면 밖에 있으면 가장자리에 작은 마름모로 위치를 알려 준다.

| 유적 | 수 | 방식 | 효과 |
|---|---|---|---|
| **사령 오벨리스크** | 4 | 점령: 반경 40 안에 4초 머물기. 용사가 범위 안에 있으면 멈추고, 벗어나면 천천히 줄어듦 | 점령하면 내 거점이 된다. 반경 110 안의 용사에게 영혼 화살을 쏘고, 근처에서 플레이어 체력 회복. 대빙의 +10% |
| **성광 첨탑** | 2 | 파괴: 체력 900의 용사 편 구조물. 주문과 군단으로 공격 | 플레이어가 220 안에 오면 깨어나 7초마다 용사 3명을 부르고 주변 용사를 회복한다. 부수면 영혼 보석 60, 대빙의 +20% |
| **봉인된 보물고** | 2 | 획득: 반경 90에 들어가면 정예 수호대(체력 3배, 공격 1.4배) 4명이 깨어남. 모두 처치하거나 빙의한 뒤 상자에 닿기 | 즉시 레벨업 카드 1회, 대빙의 +15%, 체력 40 회복 |

- 오벨리스크는 영역을 넓히고, 첨탑은 까다로운 적을 처치하는 목표, 보물고는 추가 버프를 고르는 기회다.
- 첨탑은 빙의할 수 없다. 한 번 점령, 파괴, 개방한 유적은 그 판 동안 그대로 유지된다.

### 4.9 승리와 패배
- 승리: 용사 레온을 처치한다 (`final: true` 보스).
- 패배: 플레이어 사망 또는 제단 파괴
- 결과 화면: 생존 시간, 레벨, 처치 수, 최대 군단, 되살린 마물, 빙의 수, 타락시킨 영웅
